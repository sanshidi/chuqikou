# 出气口

本地情绪发泄小工具（纯静态页）。写完就散、点出气袋、跟着呼吸缓一缓。

**内容仅留在本机浏览器，刷新即清空；不上传服务器。**

## 本地预览

```bash
cd vent-mvp
python3 -m http.server 8787 --bind 127.0.0.1
```

打开：http://127.0.0.1:8787/

## GitHub Pages

将本目录作为仓库根目录（或 `/docs`）推送后，在仓库 Settings → Pages 选择对应分支即可。无需构建步骤。

## 功能对照

| 优先级 | 功能 | 实现 |
|--------|------|------|
| P0 | 写完销毁仪式 | 撕碎 / 吸入虚空 / 气球放飞 |
| P0 | 本地承诺文案 | 页面内明确说明 |
| P0 | 免责声明 + 热线 | 页脚：400-161-9995、生命热线 |
| P1 | 出气袋 | 点击反馈 + Web Audio |
| P1 | 呼吸引导 | 销毁/出气后可选约 45 秒 |
| P2 | 情绪强度滑条 | 0–10，仅本页 |

## 不做

公共动态、聊天、AI、账号、具象暴力内容。

## 文件

- `index.html` — 结构与文案
- `styles.css` — 移动优先暖暗色 UI
- `app.js` — 交互与本地音效
