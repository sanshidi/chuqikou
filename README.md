# 出气口

深夜巷口的压力释放阀 —— 本地情绪发泄小站。写完就散、玩几局出气小游戏，然后缓一缓。**内容只留在本机，不上传、无账号。**

## 设计方向

**隐喻**：雨夜巷弄里的蒸汽排气口 / 霓虹压力阀。蒸汽往上冒、霓虹在湿沥青上反光，像夜市摊位牌一样把出气方式排成一排。

**调色**：
| 角色 | 色值 | 用途 |
|------|------|------|
| 深墨 | `#0c0a12` | 底色 / 巷影 |
| 淤紫 | `#2a1f3d` | 面板 / 摊位底板 |
| 热洋红 | `#ff3d7f` | 主霓虹 / CTA / 怒气 |
| 青蒸汽 | `#5ce1e6` | 次霓虹 / 冷静 / 反馈光 |
| 纸屑黄 | `#f4e8d8` | 便签 / 正文浅色 |
| 雨霓虹黄 | `#ffe566` | 偶尔点缀摊位招牌 |

**字体**：展示用 [ZCOOL XiaoWei](https://fonts.google.com/specimen/ZCOOL+XiaoWei)（巷口招牌感），正文 [Noto Sans SC](https://fonts.google.com/specimen/Noto+Sans+SC)。

**布局**：游戏机厅 / 夜市摊位板 —— 顶部英雄区带互动蒸汽阀，下方出气方式网格（不是 SaaS 卡片墙）。斜切角、霓虹描边、湿地面反光；避免圆角灰阴影模板。

**动效**：响应用户动作（砸、戳、撕）；仅进页一次蒸汽冒出；尊重 `prefers-reduced-motion`。

## 功能

| 类型 | 内容 |
|------|------|
| 仪式 | 写下 → 撕碎 / 吸入虚空 / 气球放飞（纯本地） |
| 情绪 | 强度滑条（仅本页） |
| 舒缓 | 销毁/出气后可选呼吸引导 |
| 页脚 | 非医疗免责 + 危机热线 400-161-9995、生命热线 |

### 出气小游戏（抽象物件，无具象暴力）

1. **出气袋** — 连点出气，Web Audio 闷响  
2. **泡泡膜** — 戳破泡泡网格  
3. **砸盘子** — 点盘子碎裂粒子  
4. **气球扎破** — 戳浮起的气球  
5. **键盘宣泄** — 狂按填满怒气条再释放  
6. **捏压力球** — 按住捏扁再弹回  
7. **碎纸机** — 拖入/输入文字粉碎动画  
8. **消火** — 打地鼠式戳灭上升的「火」图标  
9. **甩飞便签** — 把烦恼便签甩出屏幕  
10. **碎砖块** — 简易打砖块减压  
11. **敲木鱼** — 轻点木鱼，柔和音效，稳住节奏
