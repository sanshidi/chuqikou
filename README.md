# 出气口

深夜巷口的压力释放阀 —— 本地情绪发泄小站。写完就散、玩几局出气小游戏，然后缓一缓。**内容只留在本机，不上传、无账号。**

## 设计方向

**隐喻**：雨夜巷弄里的蒸汽排气口 / 霓虹压力阀。蒸汽往上冒、霓虹在湿沥青上反光，像夜市摊位牌一样把出气方式排成一排。

**调色**：
| 角色 | 色值 | 用途 |
|------|------|------|
| 深墨 | `#0c0a12` | 底色 / 巷影 |
| 淤紫 | `#2a1f3d` | 面板 / 摊位底板 |
| 热洋红 | `#ff3d7f` | 主霓虹 / CTA / 怒气 |
| 青蒸汽 | `#5ce1e6` | 次霓虹 / 冷静 / 反馈光 |
| 纸屑黄 | `#f4e8d8` | 便签 / 正文浅色 |
| 雨霓虹黄 | `#ffe566` | 偶尔点缀摊位招牌 |

**字体**：展示用 [ZCOOL XiaoWei](https://fonts.google.com/specimen/ZCOOL+XiaoWei)（巷口招牌感），正文 [Noto Sans SC](https://fonts.google.com/specimen/Noto+Sans+SC)。

**布局**：游戏机厅 / 夜市摊位板 —— 顶部英雄区带互动蒸汽阀，下方出气方式网格（不是 SaaS 卡片墙）。斜切角、霓虹描边、湿地面反光；避免圆角灰阴影模板。

**动效**：响应用户动作（砸、戳、撕）；仅进页一次蒸汽冒出；尊重 `prefers-reduced-motion`。

### 出气小游戏（精选 6 个）

1. **出气袋** — 连点出气  
2. **泡泡膜** — 戳破泡泡网格  
3. **砸盘子** — 碎裂粒子  
4. **键盘宣泄** — 怒气条狂按释放  
5. **捏压力球** — 按住捏扁弹回  
6. **敲木鱼** — 轻点稳住节奏  

## 不做

公共动态、聊天、AI、账号、上传用户内容、具象打人。

## PWA

可安装到主屏幕（`manifest.webmanifest` + `sw.js` 离线缓存静态资源）。录音数据仍只在本机 IndexedDB。

## 移动端

为减少误触放大，页面 `viewport` 设为 `maximum-scale=1, user-scalable=no`；需要系统级放大可改用系统辅助功能。按住说话区域使用 `touch-action: none`，不受影响。

## 文件

- `index.html` — 结构与文案  
- `styles.css` — 霓虹巷口 UI  
- `js/app.js` — 枢纽、仪式、呼吸、音效  
- `js/games.js` — 各小游戏  
- `js/pool.js` — 情绪池（录音 / 变声 / 泡泡）
